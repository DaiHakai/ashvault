- **File:** `piranesi-gothic-arch.jpg`
- **Work:** *Le Carceri d'Invenzione*, plate XIV: *The Gothic Arch*
- **Artist / date:** Giovanni Battista Piranesi, circa 1745–1750
- **Source:** https://commons.wikimedia.org/wiki/File:Giovanni_Battista_Piranesi_-_Le_Carceri_d%27Invenzione_-_First_Edition_-_1750_-_14_-_The_Gothic_Arch.jpg

The file is used as a subdued in-game architectural backdrop, with a dark overlay for readability.
